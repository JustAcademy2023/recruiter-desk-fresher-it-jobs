# The Recruiter's Desk: What Recruiters Expect From Freshers Entering IT Industry

An interactive, responsive landing page that lets Hyderabad freshers sit at a recruiter's desk and see what gets noticed in an IT application. Built with plain HTML, CSS and JavaScript, so it works on GitHub Pages with zero setup.

## What is inside

- A 30 second resume scan where the recruiter's notes light up line by line
- Four flip cards on direction, basics, proof and attitude
- A "Are you desk ready?" checklist with a live readiness meter
- Course and blog cards with fully clickable links
- Sticky header, responsive layout and a full footer
- Palette: dark green, brown, blue and peach
